# 靈芝視覺分析與分揀系統 (Lingzhi Mushroom Vision Analysis & Sorting System)

## 專案概述
本儲存庫包含自動化靈芝分揀機的電腦視覺模組。系統結合了 YOLO 深度學習模型（用於影像分割與關鍵點偵測）以及 OpenCV 傳統影像處理技術，來進行即時的靈芝品質評估。

核心功能包含：量測長軸以進行長度標準化、使用色彩空間閾值分析白邊與主體的比例，並將品質分為不同等級（極品 / Perfect、普通 / Normal、劣質 / Bad）。此外，系統還具備穩健的追蹤與連續累加計數邏輯，專為在分揀滑道上連續移動的物件所設計，不會在每個影格重置計數。

## 程式碼架構說明

本專案分為針對靜態資料集的批次處理腳本、針對攝影機串流的即時處理腳本，以及資料前處理工具。

### 1. 資料前處理與實用工具
* **HEIC 轉 JPG 工具 (`Heic2Jpg.py`)**: 使用 `pillow_heif` 的批次轉換工具，可將資料夾內的 `.HEIC` 圖片轉換為標準的 `.jpg` 格式，以利後續處理。
* **批次物件裁切工具 (`MusshSplit.py`)**: 此腳本會遍歷資料夾，套用 YOLO 影像分割（信心值閥值 conf=0.5），使用位元運算提取獨立的靈芝影像，並在不改變原始比例的情況下，沿著遮罩邊緣緊密裁切，最後儲存為 `.png` 檔案。

### 2. 基礎影像分割與標記
* **腳本 1 - 批次 (`Bodydetect.py`)**: 讀取輸入資料夾中的靜態圖片，套用 YOLO 分割模型，提取物件遮罩，並在偵測到的靈芝周圍畫上紅色輪廓，最後儲存標記後的圖片。
* **腳本 2 - 即時 (`BodyDetectRealtime.py`)**: 開啟攝影機進行即時影像分割。使用 Alpha 混和技術將偵測到的靈芝塗成紅色，並在有新物件進入畫面時，跨影格保持連續的累加計數。

### 3. 色彩分析與比例計算
* **腳本 3 - 即時 (`BodyDetectRealtimeWhite.py`)**: 裁切偵測到的邊界框以進行色彩比例分析。透過過濾 RGB 數值來識別白邊（標記為藍色）與主體區域（標記為紅色），計算白邊佔主體的百分比，並將結果與連續計數一起顯示在即時畫面上。
* **HSV 偵錯/視覺化工具 (`HSV+OTSUPhoto.py`)**: 處理單張圖片以測試 HSV 閾值邏輯。分離出靈芝後，對白邊和紅色主體套用精確的 HSV 範圍，並彈出獨立的 OpenCV 視窗來顯示原始裁切圖、獨立的白邊遮罩與主體遮罩。

### 4. 尺寸量測（橢圓擬合）
* **腳本 4 - 批次 (`BodyDraw.py`)**: 批次處理圖片，對分割遮罩的形態學輪廓進行橢圓擬合。計算長軸長度（以圖片寬度進行標準化），畫出橢圓與軸線，並將尺寸資料匯出至 Excel 檔案 (`mushroom_length.xlsx`)。
* **腳本 5 - 即時 (`BodyDrawReal.py`)**: 將橢圓擬合與長軸量測邏輯套用至即時攝影機畫面。連續追蹤長軸長度（包含像素與標準化格式），並在退出程式時將即時串流資料匯出至 Excel 檔案。

### 5. 關鍵點偵測與追蹤
* **腳本 6 - 即時 (`DisKeypointRealtime.py`)**: 利用 YOLO 姿勢/關鍵點模型追蹤靈芝上的三個特定點（左、右、根部）。實作了**卡爾曼濾波器 (Kalman Filter)** 來穩定並平滑化隨時間變化的關鍵點座標，計算點與點之間的距離，並將記錄批次儲存至 Excel 檔案。
* **腳本 7 - 批次 (`DistanceKeypoint.py`)**: 對資料夾內的靜態圖片進行關鍵點偵測。計算左右點之間，以及左點與根部之間的標準化歐幾里得距離，並將完整的空間資料匯出至 Excel 檔案。

### 6. 進階處理流程與品質分級
* **腳本 8 - 即時 (`finalEdit1.py`)**: 結合基於質心的追蹤、白邊比例分析與基於橢圓的長度量測的綜合處理流程。具備穩定的物件計數系統，利用跨影格間質心的歐幾里得距離來偵測並計算進入畫面的新靈芝。
* **腳本 9 - 即時 (`finalEdit2.py`)**: 擴充了腳本 8，導入了 `quality_dispatch` 評級函式。根據特定的長度閾值與白邊比例組合，將靈芝即時分類為 `perfect`（極品）、`normal`（普通）或 `bad`（劣質）。
* **腳本 10 - 批次 (`finalEdit2readfile.py`)**: 最終版本的批次品質評估腳本。使用改良的 HSV 色彩空間邊界（而非嚴格的 RGB）來更精確地分離白邊。套用完整的形態學閉合、橢圓擬合與比例計算來對圖片進行評估，輸出高度詳細的標記圖檔與全面的 Excel 報告。
